# vdx-knowledge

Complete VDX language reference, runtime behavior, internals, and troubleshooting for AI agents.

## Install

```bash
npx skills add bouclem/vdx --skill vdx-knowledge
```

## Contents

- `SKILL.md` — Main reference (architecture, key behaviors, limitations, build config)
- `references/internals.md` — Deep internals (token types, AST nodes, value system, scope, dispatch, error handling)
- `examples/examples.vdx` — Working code demonstrating edge cases, type promotion, truthiness, scope, const enforcement

## Usage

Activate this skill when understanding VDX architecture, debugging interpreter behavior, or needing deep language knowledge. Covers the lexer→parser→interpreter pipeline, value system, scope mechanics, function resolution, and known limitations.
