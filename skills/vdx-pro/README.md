# vdx-pro

VDX coding standards, best practices, and production-quality code guidance for AI agents.

## Install

```bash
npx skills add bouclem/vdx --skill vdx-pro
```

## Contents

- `SKILL.md` — Main instructions (naming, structure, syntax, safety, pitfalls)
- `references/patterns.md` — Code patterns (singleton, data class, stack, config, etc.)
- `examples/examples.vdx` — Complete working demo of all VDX features
- `examples/utils.vdx` — Import companion file for examples

## Usage

Activate this skill when writing, reviewing, or refactoring VDX code. It provides naming conventions, structural guidelines, safety rules, and common pitfall warnings specific to the VDX language.
